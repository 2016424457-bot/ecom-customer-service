## 阶段 1：Brainstorm 定稿

- **用户关键原话**
  - 初始需求：「把 query_faq 的内部实现从关键词查表升级成向量语义检索，工具的入参出参契约保持不变」；要求「全程走 Superpowers 流程，技能自动触发」，「产出不是可单测代码的任务，把 TDD 那步换成拿标注样例或评估集跑一遍验证」。
  - 运行环境追问的回答：「按你的判断来」。
  - 中途叫停：「停」「给你一些源码」，随后给出 embedding、切分、表格切分、Milvus、双写、挖矿、去重的参考实现，并要求「再根据刚才的大纲，依据这些源码进行参照和修改」。
- **关键产出**
  - 设计文档：`docs/superpowers/specs/2026-10-22-ch03-knowledge-base-design.md`（待评审）。
  - 关键决定：嵌入走 OpenAI 兼容 BGE-M3（硅基流动），不本地装 torch；Milvus 用 Lite 本地文件，避免 Docker/Colima；定时任务用 CLI + cron，不引入 APScheduler；MySQL 增 `source_doc` 用于按来源幂等重建；`query_faq` 契约保持 `keyword → {keyword,count,items[question,answer,category]}` 不变。
- **用户拒绝/纠偏**
  - 我最初倾向本地 sentence-transformers + Docker Milvus；用户用源码明确纠偏为 OpenAI 兼容 embedding + `MilvusClient`，并给出 `AsyncOpenAI` 单例、`MarkdownHeaderTextSplitter`、INT64 主键 + `dense` 字段等具体实现。
  - 用户给源码时明确要求“参照和修改”，不是另起一套。
- **翻车与返工**
  - Builder 复核 subagent 因上游 402 Insufficient Balance 中断；按 Superpowers 兜底规则由我以 builder 视角自检，补了在线接线、工具超时、CLI 建连、`data/` 目录等会逼人猜错的点。
  - 沙箱禁止访问 PyPI/HuggingFace/硅基流动；依赖安装与真实嵌入调用需在用户终端执行。
  - 本机 Docker/Colima 未运行，Milvus standalone 不可用；改 Milvus Lite，并在设计中记录单进程文件锁限制。

## 阶段 15：Code Review 结论与修复

- **用户关键原话**：无新增。
- **评审结论**：reviewer 给 **「Ready to merge: With fixes」**；1 个 Critical、4 个 Important、9 个 Minor。
- **已修**
  - **Critical 1**：`finalize_staging` 在无 `extracted` 行时提前返回，导致上次失败留下的 pending 向量永远不再重试。改为 `sync=True` 时即使无新行也调用 `vectorize_pending`；补 2 条回归测试。
  - **Important 2**：`embed_texts` 未按 `data[].index` 对齐。改为排序并校验 index 完整/唯一；补乱序与重复 index 测试。
  - **Important 3**：`MilvusSearcher.__init__` 同步连接 Milvus，阻塞事件循环。改为 `search` 内 `acall` 懒初始化，`ensure_collection` 加进程内缓存。
  - **Important 4/11**：`reset_source` 先提交 MySQL 删除再删 Milvus，避免崩溃后留下 `done` 行但无向量；`build_document` / `build_faq` 先读文档/取 FAQ 再 reset，解析失败不会清空旧数据。
  - **Important 5**：`--phase all` 在 Milvus Lite 单进程下不可执行；删除 `all`，`--phase` 改为必填，计划与 README 同步为分阶段执行。
  - **重分级 Important 10**：挖矿分类加白名单，非法/超长回退「其他」，避免 `VARCHAR(255)` 插入失败把游标卡死。
  - **Minor 12/13**：`ECOM_BASE_URL` 生效；`mine_knowledge --loop` 每轮释放 Milvus 客户端锁。
  - **测试补强**：below-threshold、空 Milvus 集合、检索异常上抛、`stream_chat` 超时接线、UUID 化 source。
- **延期 Minor**：6（混合散文/小表不递归切）、7（空 KB 无 warning）、8（集成测试仍用默认 `DATABASE_URL`）、14（早期 `source_doc=''` 旧行不在 `--reset` 范围）。
- **复测**：147 单测、18 集成、路由 6/6、挖矿 5/5、检索 hit@1/hit@3 10/10、验收 resume/retrieve/chat 全 PASS。
