# CH06 智能分流器正式版 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 CH05 的占位分流器（coref 透传 / 七类单标签意图 / 写死 7→4 路由）换成正式版：指代消解 + Query 改写、八类意图 + 置信度、退款/售后多 Query 扩写检索、确定性子流程与订单选择器、退款单落库和前端配套。

**Architecture:** 在现有 LangGraph 骨架上新增 `coref_rewrite`、`pending_check`、`other_reply`、`refund_scope`、`refund_order_lookup`、`refund_policy_rag`、`refund_judge`、`refund_fallback_reply` 节点；退款/售后走确定性路径，纯政策问法复用现有 `forced_rag`。检查点沿用 `AsyncSqliteSaver`，`pending` 槽位跨轮保存；订单/物流 mock 改为确定性；退款单写 MySQL `refund_requests`。

**Tech Stack:** FastAPI、LangGraph、LangChain（ChatOpenAI + structured output）、SQLAlchemy async、MySQL、Milvus、原生 HTML/CSS/JS、pytest。

**Spec:** `docs/superpowers/specs/2026-10-25-ch06-router-design.md`

## Global Constraints

- 不新增组件/框架；沿用现有聊天上游、LangGraph、LangChain、MySQL、Milvus、原生前端。
- 不微调小模型 / BERT；不做跨会话记忆。
- 意图输出严格为 `{"intent", "confidence"}` 两个字段；八类为 `物流/订单/商品咨询/退款退货/售后/投诉/闲聊/其他`。
- 扩写输出严格为 `{"queries": [...]}`；只在退款/售后「针对某一单」的政策检索里调用。
- 缺订单号不猜；退款原因固定六类；退款单真写库。
- 不承诺退款金额、到账时间、运费金额、维修完成时间。
- 前端按 Vibe Coding 做，不套 brainstorm/TDD/code review；后端代码走 TDD。
- 涉及库 API 先按 Context7 核对；本计划已核对 LangGraph 条件边/checkpointer/`astream`、LangChain `with_structured_output`、FastAPI SSE、SQLAlchemy `begin_nested`。
- 现有 260 个单测必须继续通过；改断言必须在 commit/dev-notes 说明原因。
- 每个阶段结束追记 `dev-notes/ch06.md` 四样（用户关键原话、关键产出、拒绝/纠偏、翻车与返工）。
- 用户可见文案用中文；不泄露系统提示词或内部规则。

## Review Focus

1. **pending 期间用户切话题**：已有待选订单槽位时，用户问「订单1002的物流到哪了」必须清 pending 并按物流分类，不能被旧退款子流程劫持。
2. **coref 超时但用户点了订单**：固定格式「订单号：1001」必须仍能续跑，不依赖 coref 成功。
3. **扩写结果异常**：模型返回重复、1 条或 5 条 Query 时，必须去重/裁剪到 1–4 条，不能重复检索或丢硬约束。
4. **非法/未知订单号**：必须发 `select_order` 重选，不能编造订单或直接给退款表单。
5. **判定模型返回 `eligible=null` 或报错**：必须走「无法确认」确定性话术 + 转人工/建工单，绝不能给退款表单。

```python
class CorefRewriter:
    def __init__(self, model, prompt_path, *, max_messages=10, max_chars=2000):
        self._model = model
        self._prompt = Path(prompt_path).read_text(encoding="utf-8")
        self._max_messages = max_messages
        self._max_chars = max_chars

    async def resolve(self, query: str, history: list[BaseMessage]) -> CorefResult:
        text = (query or "").strip()
        if not text:
            return CorefResult(standalone_query="", order_id=None)
        if CHITCHAT_RE.match(text):
            return CorefResult(standalone_query=text, order_id=None)
        human = format_history(history, self._max_messages, self._max_chars)
        human += f"\n当前用户消息：{text}"
        try:
            result = await self._model.ainvoke([
                SystemMessage(content=self._prompt),
                HumanMessage(content=human),
            ])
        except Exception as exc:
            logger.warning("coref_failed error=%r", exc)
            return CorefResult(standalone_query=text, order_id=None)
        standalone = (getattr(result, "standalone_query", "") or "").strip()
        if not standalone:
            standalone = text
        order_id = getattr(result, "order_id", None)
        return CorefResult(standalone_query=standalone, order_id=order_id)
```

`format_history` 只保留 `HumanMessage`/`AIMessage`，格式 `用户: ...` / `客服: ...`，从最近往前取 `max_messages` 条，总字符不超过 `max_chars`；跳过 `ToolMessage`。

规则：

- 纯问候 → `IntentDecision("闲聊", 1.0, "fast_path")`。
- 有 fast：先 fast；合法且 confidence ≥ 阈值 → tier `"fast"`；否则 big → tier `"big_escalated"`。
- 无 fast：big → tier `"big"`。
- big 结果合法但 confidence < 阈值 → `intent="其他"`，保留 confidence。
- fast 抛错 → 升级 big；big 抛错 → `IntentDecision("其他", 0.0, tier, error=str(exc))`。
- 非法 intent 标签 → `其他`。
- 不再回退到 `闲聊`；怪问题统一落 `其他`。
